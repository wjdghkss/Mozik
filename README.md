# Mozik

## 프로젝트 개요

Mozik은 AI 기반 영상 프라이버시 모자이크 웹 서비스입니다. 디지털 미디어 제작과 온라인 영상 공유가 증가하면서 영상 속 얼굴, 사람, 개인정보가 의도치 않게 노출되는 문제가 발생하고 있습니다. Mozik은 이러한 문제를 해결하기 위해 업로드된 이미지 또는 영상에서 얼굴과 객체를 탐지하고, 사용자가 원하는 영역에 모자이크 또는 블러 처리를 적용하는 웹 기반 편집 서비스를 목표로 합니다.

본 프로젝트는 2025년 추계 졸업작품발표회에서 BlurGuard 팀의 작품으로 제작되었으며, 개인의 프라이버시를 지키는 모자이크 미디어 편집 서비스를 주제로 합니다.

## 개발 배경

최근 디지털 미디어 제작자가 꾸준히 증가하면서 영상 촬영과 게시가 일상화되었습니다. 발표자료에서는 디지털 미디어 제작자가 2022년 15,333명, 2023년 35,375명, 2024년 42,378명으로 증가한 흐름을 제시하며, 이에 따라 영상 속 개인정보 보호의 필요성이 커졌음을 설명합니다.

또한 동의 없는 영상 촬영 및 게시, 무분별한 유튜브 콘텐츠로 인한 사생활 침해 사례가 증가하면서, 영상 업로드 전 개인정보를 쉽고 빠르게 보호할 수 있는 도구의 필요성이 커지고 있습니다.

## 프로젝트 목표

- AI 기반 얼굴 및 객체 탐지를 통한 개인정보 보호
- 정확도 95% 이상의 모자이크 성능 목표
- 업로드 후 빠르게 처리할 수 있는 시간 절약형 웹 서비스 구현
- 사용자가 원하는 대상만 선택적으로 모자이크 처리
- 직관적인 웹 인터페이스를 통한 편리한 미디어 편집 지원

## 주요 기능

### 1. 이미지 및 영상 업로드

사용자는 웹 화면에서 이미지 또는 영상을 업로드할 수 있습니다. 업로드된 파일은 서버에서 처리된 뒤 모자이크 결과물로 반환됩니다.

### 2. AI 기반 얼굴 탐지

YOLOv5 기반 객체 탐지 모델을 활용하여 영상 또는 이미지 속 얼굴 영역을 탐지합니다. 탐지된 얼굴 영역은 이후 모자이크 또는 블러 처리 대상이 됩니다.

### 3. 선택적 모자이크 처리

탐지된 영역 중 사용자가 원하는 얼굴 또는 객체만 선택하여 모자이크 처리할 수 있도록 설계되었습니다. 이를 통해 전체 화면을 흐리게 만드는 방식보다 더 정밀한 개인정보 보호가 가능합니다.

### 4. 등록 얼굴 제외 기능

ArcFace 기반 얼굴 임베딩 분석을 활용하여 사용자가 등록한 얼굴은 제외하고, 미등록 얼굴만 모자이크 처리하는 기능을 목표로 합니다. 이를 통해 본인 또는 허용된 인물은 유지하면서 타인의 얼굴만 보호할 수 있습니다.

### 5. 스타일 블러 처리

단순한 모자이크뿐만 아니라 스타일이 적용된 블러 처리를 통해 자연스럽고 개성 있는 영상 편집 결과를 제공하는 것을 목표로 합니다.

### 6. 작업 기록 관리

웹 서버는 회원가입, 로그인, 비밀번호 재설정, 작업 기록 저장 기능을 포함합니다. 처리한 파일명과 결과 파일명을 DB에 저장하여 사용자의 작업 이력을 관리할 수 있습니다.

## 프로젝트 차별점

### 1. 높은 탐지 정확도 목표

발표자료에서는 95% 이상의 탐지 정확도를 목표로 설정하고, 얼굴과 객체 탐지 기반으로 확실한 개인정보 보호를 제공하는 것을 차별점으로 제시합니다.

### 2. 얼굴 등록 기반 선택 처리

사용자가 등록한 얼굴은 제외하고 미등록 얼굴만 모자이크 처리하는 구조를 통해, 영상 속 모든 인물을 동일하게 흐리는 기존 방식보다 더 유연한 편집이 가능합니다.

### 3. 원클릭 업로드 기반 사용성

복잡한 편집 도구를 사용하지 않아도 파일 업로드만으로 개인정보 보호 처리를 수행할 수 있도록 사용자 친화적인 웹 인터페이스를 제공합니다.

### 4. 웹 서버와 AI 서버 분리 구조

웹 서비스는 Flask 기반으로 사용자 인증과 파일 업로드를 담당하고, AI 서버는 FastAPI 기반으로 탐지와 모자이크 처리를 담당하도록 구성되었습니다.

## 설치 방법

저장소를 클론한 뒤 필요한 라이브러리를 설치합니다.

```bash
pip install -r requirements.txt
```

환경 변수 파일을 생성합니다.

```bash
cp .env.example .env
```

`.env` 파일을 열어 DB 정보, SMTP 정보, Flask Secret Key 등을 본인 환경에 맞게 수정합니다.

## DB 설정

MariaDB에서 아래 SQL 파일을 실행합니다.

```bash
mysql -u root -p < db/schema.sql
```

## 실행 방법

### 1. 웹 서버 실행

```bash
cd web_server
python app.py
```

기본 접속 주소는 다음과 같습니다.

```text
http://127.0.0.1:5000
```

### 2. AI 서버 실행

```bash
cd ai_server
uvicorn api_main:app --host 0.0.0.0 --port 8000
```

웹 서버와 AI 서버를 분리해서 사용할 경우 `.env`의 `MOSAIC_API_URL` 값을 AI 서버 엔드포인트에 맞게 수정해야 합니다.

## 향후 개선 방향

- 탐지 정확도 향상
- MP4, MOV, AVI, WMV 등 다양한 영상 포맷 처리 안정화
- 사용자 얼굴 등록 기반 탐지 정확도 강화
- 다양한 객체 인식 목록 확대
- 모자이크 강도 및 스타일 조절 기능 개선

## 보안 및 주의 사항

`.env` 파일에는 DB 비밀번호, SMTP 계정, Secret Key 등이 포함될 수 있으므로 GitHub에 업로드하지 않습니다.

GitHub에는 `.env.example`만 포함합니다. 업로드 전 실제 개인정보가 들어간 파일이나 테스트 업로드 이미지가 포함되지 않았는지 반드시 확인해야 합니다.
